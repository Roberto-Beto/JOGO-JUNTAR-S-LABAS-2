# Jogo: Juntar Sílabas

Um jogo educativo simples em HTML/JS para alunos praticarem formação de palavras a partir de sílabas.

## Como usar

1. Faça download deste repositório como ZIP e extraia.
2. Abra `index.html` em qualquer navegador (funciona offline e em celular).
3. Para publicar online, envie os arquivos para um repositório GitHub e ative **GitHub Pages**.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie `index.html` e `README.md` para o repositório.
3. Vá em **Settings > Pages** e escolha a branch principal (geralmente `main`) e a pasta `/root`.
4. O GitHub gerará um link como: `https://seu-usuario.github.io/nome-do-repositorio/`

Pronto! Compartilhe esse link com seus alunos.
